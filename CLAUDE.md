# Margot Dauban — agent guide

Portfolio site of a freelance UI/UX designer. Read before any change. Humans: start with `README.md`.

## Stack

Single Next.js 16 app (App Router, `cacheComponents`) · Payload 3 (CMS + admin at `/admin`, French UI) · MongoDB Atlas · S3 (media) · shadcn/ui + Tailwind 4 · Biome · Vitest · Vercel. Details and why: `docs/architecture.md`.

```
src/app/(frontend)       Public site (French). Pages compose model components
src/app/(payload)        Payload admin + REST API. GENERATED by Payload: don't edit
src/collections, globals Content model (Payload configs). Labels in French, field names in English
src/components/models    Model components: one per way a doc is shown, cached by id
src/components/ui        shadcn components (CLI-managed: `pnpm dlx shadcn@latest add <name>`)
src/data                 Cached id lookups (lists, slug → id) and globals
src/lib/cache.ts         Cache tags + Payload revalidation hooks
src/payload-types.ts     GENERATED by `pnpm generate`
designs/<n>-<slug>/      Design references per issue (zip/html/png/pdf), added by scripts/add-design.sh
.claude/                 Agents, skills (payload, request, build), ponytail plugin
.github/                 Workflows, agent scripts, issue forms, labels.json
docs/                    How the repo works. Keep it true when you change behaviour
```

## Commands

```bash
pnpm dev                          # :3000, needs .env (Atlas margot-preview URL, PAYLOAD_SECRET)
pnpm generate                     # after any collection/global/admin component change
pnpm lint:fix && pnpm lint        # Biome
pnpm typecheck && pnpm test       # tsc (after next typegen) + Vitest
pnpm build                        # local only (reads DATABASE_URL: pages prerender at build). In CI, Vercel builds
```

## Hard rules

- **Caching (the core rule).** Every component that renders a Payload doc lives in `src/components/models/` and:
  - takes the doc **id** as its only data prop, starts with `'use cache'`, calls `cacheLife('model')` and `cacheTag(tags.doc('<collection>', id))`;
  - fetches its own doc with the Local API (`getPayload()` from `@/lib/payload`), and also tags every related doc it renders (e.g. `cacheTag(tags.doc('media', cover.id))`).
  - Lists and slug lookups go in `src/data/*`, return **ids only**, are cached with `tags.collection('<collection>')`. Globals: `tags.global('<slug>')`.
  - Never hand-write a tag string; use `tags` from `src/lib/cache.ts`. Revalidation hooks are added to every collection and global in `payload.config.ts`: new collections/globals go through `withRevalidation` / `withGlobalRevalidation`.
  - Runtime data (`params`, `searchParams`, `cookies`) is read inside a `<Suspense>` child, never in a cached scope.
- **Public reads = published only.** Front-end queries filter `_status: published` (Local API skips access control). Collections with content use `versions: { drafts: true }` and `publishedOrLoggedIn` read access (`src/access`).
- **Server only.** Payload Local API, env, and secrets stay on the server (`server-only`). The browser never calls Payload for site content. GraphQL is disabled.
- **Content model changes** (`src/collections`, `src/globals`): run `pnpm generate` and commit the generated files (CI fails on drift). Adding an optional field is safe. Renaming, removing, or making a field required on existing data → expand/contract (two PRs) or a Payload migration (`pnpm payload migrate:create`); the first migration also adds `"vercel-build": "payload migrate && pnpm build"` to `package.json`.
- **Admin is in French**: `labels` and `admin.description` in French; field `name`s in English camelCase. Every media has a required `alt`.
- **UI = shadcn/ui + Tailwind.** Reuse a shadcn component (add it with the CLI) before writing one. Design tokens live in `src/app/(frontend)/globals.css`. Accessible by default: semantic HTML, alt text, focus states, contrast.
- **zod at the boundary**: env (`src/lib/env.ts`), server action inputs, external API responses. Infer types (`z.infer`), don't duplicate them.
- **Ponytail.** Smallest change that works: reuse → stdlib → platform → installed dep → new code. No new dependency without a reason in the PR. Never cut validation, error handling, security, or accessibility.
- **One issue = one branch = one PR into `main`.** Conventional Commit PR title. `Closes #<n>` in the body.
- **Design references** (`designs/`): the visual spec for their issue. Read HTML as text and replicate values with tokens + shadcn; view images/PDF. Never execute, serve, import, or lint them; never edit another issue's folder.
- Don't touch `.github/`, `.claude/`, env files, or `src/app/(payload)` unless the issue is about them.
